Printer Farmlord · install guide

Turn a spare Android phone into your print farm server

Follow these steps once. Afterwards the phone sits next to your Bambu printers, runs the dashboard day and night, and you open it from anywhere through Tailscale. The screens below show exactly what you'll see. All values are examples.

  • Bambu printers with LAN mode
  • A spare Android phone
  • A free Tailscale account
  • About 10 minutes
Printer: step 1Server phone: steps 2–6Your own phone or laptop: step 7Optional: step 8
STEP 1On each printer

Turn on LAN mode and note three details

  1. On the printer's touchscreen, open Settings → Network.
  2. Switch on LAN Only and Developer Mode.
  3. Write down the IP address, serial number and access code. Setup asks for all three.

The access code works like a password for the printer. Don't share it or post it anywhere.

STEP 2Server phone

Connect the phone and switch on Tailscale

  1. Connect the phone to the same Wi‑Fi as the printers and leave it plugged in.
  2. Install Tailscale from the Play Store, sign in and switch it on.
  3. Note the phone's Tailscale address (starts with 100.) and its device name. You need them in step 7.

STEP 3Server phone

Install Termux and stop Android putting it to sleep

  1. Install Termux from F‑Droid. The Play Store version is outdated and won't install packages.
  2. Open Android Settings → Apps → Termux → Battery and choose Unrestricted.
  3. Do the same for Tailscale.

Without this, Android closes the dashboard when the screen is off for a while.

STEP 4Server phone · Termux

Paste one line to install

Open Termux, paste this, and press Enter. It installs Python, downloads Printer Farmlord and starts it. It takes about a minute.

pkg install -y python ffmpeg git && git clone https://github.com/levleon13/printer-farmlord.git && cd printer-farmlord && ./scripts/start.sh

If it stops with an error, it prints a Report it link. Open it to send the problem to the maintainer with private details already removed.

STEP 5Server phone · browser

Add your printers on the setup page

The setup page opens in the phone's browser by itself. If it doesn't, open http://localhost:8765/setup.

  1. Type the printer's name, IP address, serial number and access code from step 1.
  2. Tap Test connection. "Found a printer" means the phone can reach it.
  3. Tap Add printer, then repeat for each printer.

"No answer" usually means a wrong IP, LAN mode is off, or the phone is on a different Wi‑Fi.

STEP 6Server phone · browser

Allow other devices, set a password, finish

  1. Tick Let other devices on my network open it.
  2. Choose a password of at least 8 characters and type it twice.
  3. Tap Finish and open the dashboard. A few seconds later your dashboard appears.

Don't skip the tick box. Without it the dashboard only answers on the phone itself, and Tailscale can't reach it.

STEP 7Your own phone or laptop

Open the dashboard from anywhere

  1. Install Tailscale on your own phone or laptop and sign in with the same account.
  2. Open http://100.x.y.z:8765, using the server phone's address from step 2. The device name works too: http://print-room-phone:8765.
  3. Sign in with the password from step 6.

Never forward port 8765 on your router. Tailscale keeps the dashboard private without that.

STEP 8Optional · server phone

Start it again automatically after a reboot

  1. Install Termux:Boot from F‑Droid and open it once.
  2. Paste this into Termux:
mkdir -p ~/.termux/boot && printf '#!/data/data/com.termux/files/usr/bin/bash\ncd ~/printer-farmlord && ./scripts/start.sh\n' > ~/.termux/boot/farmlord && chmod +x ~/.termux/boot/farmlord

The start script keeps Termux awake, so the dashboard keeps running with the screen off.

Updating

In Termux run cd ~/printer-farmlord && git pull. The dashboard restarts itself within seconds; prints keep running.

Something wrong?

Use the Report a problem link on the setup page or in the error message. Setup problems are collected and fixed every Friday.

Adding printers later

Open the dashboard and use Printer settings → Add a printer. No terminal needed.
